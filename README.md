## Open Source Projects

Widely used projects built by developers and companies from Türkiye.

- [prompts.chat](https://github.com/f/prompts.chat) - Community prompt library, formerly Awesome ChatGPT Prompts.
- [vim-go](https://github.com/fatih/vim-go) - Go development plugin for Vim.
- [color](https://github.com/fatih/color) - Color package for Go terminal output.
- [gomodifytags](https://github.com/fatih/gomodifytags) - Go tool to modify and update struct field tags.
- [SAHI](https://github.com/obss/sahi) - Sliced inference for detecting small objects in large images.
- [ABP Framework](https://github.com/abpframework/abp) - Open-source web application framework for ASP.NET Core.
- [Baklava](https://github.com/Trendyol/baklava) - Trendyol's design system for consistent UI/UX.
- [VoltranJS](https://github.com/hepsiburada/VoltranJS) - Micro frontend framework by the Hepsiburada tech team.
- [Pardus](https://github.com/pardus) - Debian-based Linux distribution developed in Türkiye.

## Turkish NLP and LLMs

- [Zemberek-NLP](https://github.com/ahmetaa/zemberek-nlp) - Morphology, tokenization and normalization tools for Turkish.
- [VNLP](https://github.com/vngrs-ai/vnlp) - Lightweight, state-of-the-art NLP tools for Turkish.
- [BERTurk](https://github.com/stefan-it/turkish-bert) - Turkish BERT, DistilBERT, ELECTRA, ConvBERT and T5 models.
- [Turkish spaCy Models](https://github.com/turkish-nlp-suite/turkish-spacy-models) - spaCy pipelines for Turkish.
- [sadedegel](https://github.com/GlobalMaksimum/sadedegel) - General-purpose NLP library for Turkish.
- [Mukayese](https://github.com/alisafaya/mukayese) - Benchmarks and baselines for Turkish NLP tasks.
- [Turkish BERT NLP Pipeline](https://github.com/savasy/Turkish-Bert-NLP-Pipeline) - NER, sentiment analysis and question answering with BERT.
- [Turkish Word Embeddings](https://github.com/Turkish-Word-Embeddings) - Word embedding resources for Turkish.
- [TURNA](https://huggingface.co/boun-tabi-LMG/TURNA) - Turkish encoder-decoder language model from Boğaziçi University.
- [YTU Cosmos](https://huggingface.co/ytu-ce-cosmos) - Turkish language models from Yıldız Technical University.
- [Trendyol on Hugging Face](https://huggingface.co/Trendyol) - Turkish LLMs and models released by Trendyol.
- [Turkish NLP Guide](https://github.com/nanelimon-organization/TurkishNLPGuide) - Türkçe NLP kaynaklarını bir araya getiren rehber.
- [turkish-nlp-resources](https://github.com/agmmnn/turkish-nlp-resources) - Tools, libraries, models and datasets for Turkish NLP.

## APIs, Libraries and Open Data

### Libraries and Wrappers

- [turkish-apis](https://github.com/3rt4nm4n/turkish-apis) - List of Turkish APIs.
- [Türkiye API](https://github.com/ubeydeozdmr/turkiye-api) - REST API for provinces, districts and neighbourhoods of Türkiye.
- [turkey-neighbourhoods](https://github.com/muratgozel/turkey-neighbourhoods) - Up-to-date names of cities, districts and neighbourhoods with postal codes.
- [tr-geozones](https://github.com/epigra/tr-geozones) - Country, province, district, neighbourhood and postal code database for Laravel.
- [Kandilli Rasathanesi API](https://github.com/orhanayd/kandilli-rasathanesi-api) - Free API that combines Kandilli and AFAD earthquake data.
- [TurkishId](https://github.com/ssg/TurkishId) - Validator and generator for Turkish ID numbers (TC Kimlik No).

### Open Data

- [TCMB EVDS](https://evds2.tcmb.gov.tr) - Central Bank of the Republic of Türkiye electronic data delivery system.
- [TCMB daily exchange rates (XML)](https://www.tcmb.gov.tr/kurlar/today.xml) - Official daily exchange rates.
- [TÜİK Veri Portalı](https://data.tuik.gov.tr) - Turkish Statistical Institute data portal.
- [AFAD Deprem](https://deprem.afad.gov.tr) - Earthquake data from the Disaster and Emergency Management Authority.
- [Kandilli Son Depremler](http://www.koeri.boun.edu.tr/scripts/lst0.asp) - Latest earthquakes from Boğaziçi University Kandilli Observatory.
- [İzmir Açık Veri](https://acikveri.bizizmir.com) - İzmir Metropolitan Municipality open data portal.
- [Açık Veri](https://github.com/kaymal/acik-veri) - Curated list of open data platforms in Türkiye.
- [Turkey Earthquake 2023 GeoData](https://github.com/kalkan/Turkey-Earthquake-2023-GeoData) - Satellite and geospatial data about the 6 February 2023 earthquakes.

### Payments and e-Invoice

- [iyzico Developer Docs](https://dev.iyzipay.com) - Documentation for iyzico payment APIs.
- [iyzipay-node](https://github.com/iyzico/iyzipay-node) - Official iyzico Node.js client.
- [iyzipay-php](https://github.com/iyzico/iyzipay-php) - Official iyzico PHP client.
- [PayTR Developer Docs](https://dev.paytr.com) - Documentation for PayTR payment APIs.
- [better-payment](https://github.com/czaydev/better-payment) - One type-safe API for Turkish payment providers.
- [GİB e-Belge](https://ebelge.gib.gov.tr) - Official e-Invoice (e-Fatura) portal, guides and tools of the Revenue Administration.
- [fatura (f)](https://github.com/f/fatura) - e-Arşiv / e-Fatura invoice generator.
- [fatura (mlevent)](https://github.com/mlevent/fatura) - PHP client for GİB e-Arşiv portal: e-Fatura, e-SMM and e-Müstahsil.
